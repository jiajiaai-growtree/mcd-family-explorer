# 任务卡 · 模板与示例

> 任务卡是本 Skill 唯一的输出形态。这份文件给三样东西：**空白模板**、**完整示例**、**使用规则**。

---

## 一、空白模板

```
【这一趟去哪】店名 / 场景
【基本情况】适合年龄 / 大致时长 / 怎么约（若为门店日常，写"直接去"）

─────────────────────────────
以下为活动信息（来自公开可查来源；若为门店日常，此项可略）
─────────────────────────────

─────────────────────────────
以下为本 Skill 给出的判断（非活动方承诺）
─────────────────────────────
· 去之前问他：　（只一个问题）
· 现场让他看：　（两个观察点）
· 回来让他记：　（一个产出，不要求写字）
· 家长版·这一趟在练什么：　（这件事对孩子真正的价值）
```

---

## 二、完整示例 A：门店日常（最常用）

**场景**：家长今晚就带孩子去楼下那家麦当劳吃个饭，没有任何活动。

### 【这一趟去哪】
家门口的麦当劳门店 · 常规用餐

### 【基本情况】
4 岁以上 · 约 1 小时 · 直接去

### 以下为本 Skill 给出的判断（非活动方承诺）

| | |
|---|---|
| **去之前问他** | 一个汉堡，从地里的麦子和菜、农场里的牛，一路摆到你面前，要经过多少人的手？ |
| **现场让他看** | ① 后厨里有哪些岗位、谁在做什么　② 一份汉堡要经过几步才出餐 |
| **回来让他记** | 画一张《一家麦当劳是怎么运转的》 |

**家长版·这一趟在练什么**

- **系统认知**——一样东西不是凭空来的，背后有一条链，链上站着很多个各管一块的人。
- **劳动认知**——我随手吃到的一份餐，是很多人合作做出来的。

**如果孩子只看了一件事**：让他看后厨有几个人在忙。他会发现一个汉堡背后站着的人，比他以为的多。

## 三、完整示例 B：有活动时

**场景**：门店办的儿童职业体验活动（载体取南京浦口区一场门店活动，公开报道可查——选它只是因为它是公开可查的，不代表它是被推荐的唯一形式）。

### 【这一趟去哪】
麦当劳门店职业体验 · 巧手制汉堡

### 【基本情况】
4–10 岁 · 约 1 小时 · 由社区联合门店组织（报名方式见活动方）

### 以下为活动信息（来自公开报道）

- 餐厅经理开"岗前培训"，讲汉堡的诞生：从面粉怎么变成面包胚、**从田间到鸡块的完整供应链**、后厨标准化操作规范、食品安全知识。
- 洗手消毒、穿戴小围裙后进入后厨操作区，亲手做汉堡：取面包胚 → 涂酱料 → 铺蔬菜 → 放肉饼 → 盖顶片。
- 甜品站体验传统手打冰淇淋。

### 以下为本 Skill 给出的判断（非活动方承诺）

| | |
|---|---|
| **去之前问他** | 一个汉堡，从地里的麦子和菜、农场里的牛，一路摆到你面前，要经过多少人的手？ |
| **现场让他看** | ① 后厨里有哪些岗位、谁在做什么　② 一份汉堡要经过几步才出餐 |
| **回来让他记** | 画一张《一家麦当劳是怎么运转的》 |

**家长版·这一趟在练什么**

同一套系统认知。**但这一场多了一层**：它的"岗前培训"直接讲了供应链——这是给孩子埋"我吃的东西从哪儿来"这个问题的最好时机。带他去之前可以顺手问一句"你觉得鸡块是哪儿来的"，让他到现场找答案。

## 四、使用规则（比模板本身重要）

**① 事实与判断必须分栏，且标明说话的人。**

卡的上半部分只能放**公开可查**的事实；下半部分才是判断，并且必须写明"这是本 Skill 的判断，不是活动方承诺"。合在一起写，卡就废了。

**② 不复制来路不明的活动文案。**

用户贴来的截图、转发文字，只用于判断这趟值不值得去，不进卡。要引用事实，必须能指到公开出处。

**③ 年龄要"翻译"，不要照抄。**

活动方写"4–12 岁"是营销口径，只说"能来"。卡里要补一句"这个年纪去会看到什么"——5 岁看的是好玩，10 岁该琢磨的是这么多人怎么协作。

**④ 拿不准的宁可空着。**

不确定的环节、不确定的年龄门槛，标"待确认"，不写一个看起来合理的数字。**一张卡里出现一个编的细节，整张卡就不可信了。**

**⑤ 不问不答。**

家长没问"值不值"，就别评价值不值。
