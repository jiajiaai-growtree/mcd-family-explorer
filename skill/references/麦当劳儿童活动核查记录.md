# 麦当劳儿童主题活动 · 核查报告

核查日期：2026-10-09　｜　核查范围：麦当劳中国大陆官方渠道（mcdonalds.com.cn、官方 APP/麦麦商城）与 MCP 工具清单

---

## 结论（先说结果）

1. **"主题活动"是真实存在的**，不是推测。它是麦当劳中国官方的一条独立业务线，走「**麦麦商城 → 选门店 + 时间段 → 预约 → 到店核销**」的流程。
2. **其中确有面向儿童的活动**，而且不止一个：
   - **麦当劳过家家派对·尊享版** —— 4–12 岁，长期在办（至 2027-12-31）
   - **消防员体验营** —— 5–12 岁，麦当劳 + 当地消防站联合
3. **这两个活动的形态本身就是"研学"**：一个带**证书**，一个带**亲子餐 + 沉浸式体验**。做研学不需要替它们编教育意义，只需要把它们的教育价值说清楚、按年龄筛准。
4. **上一轮我的一个判断错了，这里更正**：我说你提供的那条"118 元/儿童"更像第三方招募——不对。官方"过家家派对·尊享版"的定价规则正是**"每增加一位儿童增加 118 元"**，与你给的价格完全吻合。它大概率就在官方体系内，能通过 MCP 查到。

---

## 一、主题活动为真 —— 证据链

官方规则原文（麦当劳中国官网公告）描述的参与路径是：

> 麦当劳注册会员点击进入麦当劳官方 APP 打开【麦麦商城】→ 点击活动页面 → 点击【预订】→ **选择附近的门店及预约时间段**，确认订单后即可获取预约体验券

这个"选门店 + 选时间段 + 下单"的流程，与 MCP 里那五个工具的职责**一一对应**：

| 官方流程 | 对应 MCP 工具 |
|---|---|
| 选择城市 | `query-party-city` |
| 选择附近门店 | `query-party-store` |
| 选择日期 | `query-partystore-date` |
| 选择时间段（场次） | `query-partystore-session` |
| 确认订单 | `party-order-create` |

**旁证**：麦当劳 MCP 版本日志显示，2026-07-29 发布的 1.0.7 版本"新增麦当劳派对、品鉴会等主题活动查询、预约与下单功能"。也就是说这条链路是官方为这类活动专门开放的。

## 二、儿童活动清单

### 1. 麦当劳过家家派对·尊享版 ✅ 儿童活动

| 项目 | 内容 |
|---|---|
| 适用年龄 | **4–12 岁儿童** |
| 活动时长 | 约 **90 分钟** |
| 成团人数 | 每场 **5 位儿童起订**，最高 12 位（含） |
| 价格 | 基准价含在套餐内，**每增加一位儿童 +118 元** |
| 预约要求 | 提前 **3 天** 预订，每场需满 5 位儿童 |
| 内含 | 沉浸式派对体验 + 1 份开心乐园餐 + 1 份套餐（麦辣鸡腿堡套餐 / 板烧鸡腿堡套餐，二选一）+ 随机玩具 1 款 |
| 活动期 | 2026-09-09 至 **2027-12-31**（长期） |
| 入口 | 官方 APP → 麦麦商城 →【麦当劳过家家派对-尊享版】 |
| 出处 | 麦当劳中国官网 2026-09-09 公告；场次/价格细节见腾讯网、搜狐转载报道 |

> **注意**：官方的公开描述只写到"沉浸式派对体验"，没有逐条列出派对里的环节。你提供的那条招募里"探秘厨房 / 自打甜筒 / 一日员工 / DIY 汉堡"四个环节，可能来自门店实际执行版本或招募方的具体化描述，**不能直接当成官方活动内容引用**。

### 2. 消防员体验营 ✅ 儿童活动

## 三、海外与中国台湾地区的同类模式（仅作旁证，MCP 不覆盖）

麦当劳的"儿童职业体验营"在其它市场是长期成熟项目，说明这不是临时玩法：

- **中国台湾地区｜小麥麥體驗營**：2015 年推出至今累计超 **43 万名**参与者；2026 年针对 **3 岁以上**儿童（制服适合身高 120cm 以内）；费用 988 新台币，含体验 + 快乐儿童餐四件组 + **小麥麥證書** + 专属名牌 + 迷你麦当劳组；分"小小经理"（含食材守護員、漢堡組裝師等关卡）与"小小款待大使"两种角色。出处：麦当劳台湾官网 2026-05-28。
- **菲律宾｜Kiddie Crew Workshop**：1991 年开办至今 35 年，3–12 岁，5 天课程，含 values formation（纪律、责任、勤奋、团队）、食物制作、舞蹈、手工，毕业发证书，2026 年学费 1,150 比索，700+ 门店参与。出处：PhilSTAR Life、WhenInManila 2026 年报道。

> ⚠️ 港澳台地区与海外活动**不在麦当劳中国 MCP 的覆盖范围内**（MCP 明确"面向中国大陆地区，不含港澳台"）。此处仅用于说明该模式成熟度，不能写进产品功能里。

## 四、这对产品意味着什么（更新后的判断）

**入口对了。** 原来担心的"官方活动抓不到、只有第三方招募"基本不成立——官方确实有一条完整的、MCP 能打通的儿童活动预约链路。所以产品的主路是：

> 按孩子年龄 + 可约时间，从官方主题活动里筛出能去的场次，配一张研学卡，走完预约。

**"年龄筛选"这一层现在有了硬数据支撑**（派对 4–12 岁、消防营 5–12 岁、消防营须成人陪同），不再是猜的。

**仍需调整的地方**：品鉴会要从"儿童研学"里拿掉或降级——它是成人场。
